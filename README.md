# PortifolioSiteClinica

Website institucional moderno, responsivo e de alta performance desenvolvido para clínicas de dermatologia, estética médica e cuidados com a pele.

## ✨ Tecnologias Utilizadas
- **HTML5** semântico e estruturado para SEO
- **CSS3 Moderno** (Variáveis CSS, Flexbox, Grid, Glassmorphism, Microinterações)
- **JavaScript Vanilla (ES6+)** para interatividade, modais, carrossel de antes/depois e animações
- **Design Responsivo** otimizado para dispositivos móveis, tablets e desktops

## 📂 Estrutura de Arquivos
```
PortifolioSiteClinica/
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   └── images/
├── index.html
└── README.md
```

## 🚀 Como Visualizar
Basta abrir o arquivo `index.html` em qualquer navegador web ou utilizar uma extensão como o Live Server no VS Code.
